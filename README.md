# LMS Backend — Docker Compose Hw

## Требования
- Docker 24+ и Docker Compose V2
- Репозиторий содержит файлы (для Docker):
  - `docker-compose.yaml`
  - `.env.example`
  - `.gitignore`
  - `Dockerfile`

## Шаги по запуску
1. Создать `.env` из шаблона:
```bash
   cp .env.example .env
```
2. Собрать и запустить контейнер:
```bash
   docker compose up --build
```
3. Пройти по ссылке: http://127.0.0.1:8000/ (админка: /admin/)

### Что происходит автоматически при старте

- Выполняются миграции.
- Если SEED_DEMO=1 — автоматически создаётся суперпользователь
admin@mail.ru / admin123 (если его ещё нет) и заливаются демо-данные (курсы и уроки).

Приложение сразу готово к проверке, ничего вручную делать не нужно.
